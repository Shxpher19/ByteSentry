All-in-One Features

ByteSentry brings together moderation, music, economy, games, analytics, and developer tools in one sleek package.

🔧 Moderation

  • Auto-Moderator with profanity filters and escalation
  • Mute, unmute, temp-ban, slowmode, lockdown
  • Warn, mod-note, view/clear warnings, mod-logs
  • Set/reset nicknames, ticket system, reaction roles

🎶 Music

  • Play from YouTube, join/leave voice channels
  • Volume control, shuffle, skip, stop
  • Queue management, nowplaying with metadata
  • Search and lyrics lookup

💰 Economy

  • Daily rewards and streak bonuses
  • Transfer coins, beg, rob, leaderboards
  • Shop, inventory tracking, XP & leveling
  • Birthday announcements

🎮 Games

  • Trivia quiz with timed buttons
  • Hangman and Wordle
  • Tic-Tac-Toe with live state
  • Train & level up mini-RPG

📊 Analytics

  • Command usage stats
  • Auto-prune old messages
  • Mod-log dashboard via web endpoint

🛠 Developer Tools

  • Hot-reload commands in development
  • Runtime `/eval`, `/pingapi`, `/backupdb`
  • Customizable settings per guild
