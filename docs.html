Getting Started

  1. Clone the repo
    git clone https://github.com/your-username/ByteSentry.git
  2. Install dependencies
    npm install
  3. Create a .env file with: 
    BOT_TOKEN=your_bot_token
CLIENT_ID=your_app_client_id
OWNER_ID=your_discord_id
  4. Deploy slash commands
    node deploy-commands.js
  5. Run the bot
    node index.js
  6. Development mode (hot-reload)
    NODE_ENV=development node index.js
  7. Dashboard
    node dashboard.js (make sure express is installed)

Configuration & DB

We use quick.db (SQLite). Your data file appears as database.sqlite in the root. Many commands let you configure channels or values per guild via slash commands.
