Slash Command Reference

Command Description
/help [command]List all commands or show details
/settings view|setView or update server settings
/prefix [value]View or change command prefix
/timezone [zone]View or set default timezone
/time [zone]Show current time in a timezone
/inviteGet the bot’s invite link
/uptimeShow bot uptime and resource usage
/serverbannerDisplay server banner
/servericonDisplay server icon
/slowmode <sec>Set or clear channel slowmode
/tempban <user> <mins>Ban a user temporarily
/mute <user> [mins]Mute a member (text & voice)
/unmute <user>Unmute a member
/warn <user> <reason>Warn a user with mod-log
/modlogs <user>View all warnings for a user
/removemoderations <user>Clear warnings & unmute
/setnick <user> <nick>Change a member’s nickname
/resetnick <user>Reset a member’s nickname
/lockdown <true|false>Lock or unlock all text channels
/modnote <user> <note>Add an internal note to a user
/play <URL>Play or enqueue a song
/skipSkip the current song
/stopStop playback and clear queue
/volume <0–200>Adjust playback volume
/shuffleShuffle the music queue
/nowplayingShow current track info
/search <query>Search YouTube (top 5 results)
/lyricsGet lyrics for the current song
/transfer <user> <amt>Send coins to another user
/inventoryView your items
/daily-streakClaim your daily coins
/begBeg for random coins (30m cooldown)
/rob <user>Attempt to rob another user (1h cooldown)
/leaderboardShow top 10 richest users
/rank [user]View XP & level
/birthday set|viewSet or see your birthday
/triviaAnswer a multiple-choice question
/hangman start|guessPlay hangman
/wordle start|guessPlay Wordle
/tictactoe start|movePlay Tic-Tac-Toe
/lvlupTrain to gain XP & level
/statsShow top command usage
/autoprune set|runConfigure or run auto-prune
/evalEvaluate JS (owner only)
/pingapiCheck WS & DB latency
/backupdbBackup the database file
